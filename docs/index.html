맥을 켤 때 기본으로 나는 "둥~" 소리 대신 내가 고른 음악이나 짧은 효과음이 나오면 어떨까 싶어서 만든 작은 앱입니다. 메뉴 막대에 계속 떠 있거나 메모리를 차지하지 않고, 부팅 시 LaunchDaemon으로 한 번 실행되어 사운드를 재생한 뒤 바로 종료됩니다.

Apple Silicon(arm64)과 Intel(x86_64)을 모두 지원하는 Universal Binary로 빌드했으며, macOS 13.0 이상에서 사용할 수 있습니다.

주요 기능

  • 최대 5개 사운드 등록: .mp3, .m4a, .wav, .aiff 등 원하는 오디오 파일을 최대 5개까지 목록에 넣고 삭제할 수 있습니다. 각 항목마다 바로 미리듣기도 가능합니다.
  • 선택 재생 / 랜덤 재생: 목록에서 지정한 한 곡만 고정으로 재생하거나, 매 부팅마다 목록 중 랜덤으로 한 곡을 재생하도록 고를 수 있습니다.
  • 가벼운 백그라운드 실행: 실제 재생을 담당하는 헬퍼(MacBootSoundPlayer)가 macOS 기본 afplay로 재생만 하고 즉시 종료되므로 로그인 속도 지연이 거의 없습니다.
  • 시스템 설정 시동음 연동: macOS 시스템 설정의 '시동 시 사운드 재생' 상태를 앱 안에서 스위치로 확인하고 바로 켜거나 끌 수 있습니다.
  • 한국어 / 영어 지원: 시스템 언어가 한국어면 한국어로, 그 외 언어면 영어로 표시되며 하단에서 직접 전환할 수도 있습니다.

설치 방법

  1. MacBootSound.dmg 파일을 열어 MacBootSound.app을 Applications(응용 프로그램) 폴더로 드래그합니다.
  2. 응용 프로그램 폴더에서 MacBootSound를 실행합니다.

Apple Developer ID 공증이 없는 로컬 서명(ad-hoc) 앱이므로, 다른 맥으로 옮겨 처음 실행할 때 Gatekeeper 확인 창이 뜰 수 있습니다. 앱 아이콘을 우클릭 → 열기로 실행하거나, 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기로 한 번만 허용해 주세요.

사용 방법

  1. 상단의 추가... 버튼을 눌러 부팅 시 재생할 사운드 파일을 추가합니다(최대 5개).
  2. 재생 방식에서 선택한 사운드 또는 랜덤 재생을 고르고, 활성화 스위치와 음량을 맞춥니다.
  3. 부팅 사운드 등록 버튼을 눌러 Touch ID 또는 관리자 암호를 한 번 승인합니다.
  4. 백그라운드 실행 테스트 버튼을 누르면 실제 부팅 데몬처럼 한 번 재생된 뒤 자동 종료되는지 바로 확인할 수 있습니다.

한 번 등록을 마친 뒤에는 사운드를 추가·삭제하거나 음량을 바꿔도 다시 암호를 묻지 않고 즉시 반영됩니다. 또한 등록된 음원은 /Library/Application Support/MacBootSound/ 폴더에 복사되므로, 이후에 원래 고른 원본 파일을 삭제해도 부팅 시 정상적으로 재생됩니다.

FileVault 사용 여부에 따른 재생 시점

앱 상단 배너에서도 현재 맥의 FileVault 상태를 바로 확인할 수 있는데, 켜짐/꺼짐에 따라 소리가 들리는 시점에 차이가 있습니다.

  • FileVault가 켜져 있는 경우: 전원 켠 직후 뜨는 암호 입력 화면은 macOS가 부팅되기 전 디스크 잠금을 해제하는 단계입니다. 암호를 입력해 잠금을 풀어야 비로소 macOS가 부팅되며 사운드가 재생됩니다. 이때 기본 시동음과 소리가 겹칠 수 있어 앱 안에 끄기 안내와 버튼이 표시됩니다.
  • FileVault가 꺼져 있는 경우: 별도 잠금 해제 없이 macOS가 바로 부팅되면서 사용자 로그인 전 시동 시점에 사운드가 재생됩니다. 이 경우에는 중복 경고 문구도 뜨지 않습니다.

전원을 누르자마자 울리는 Apple 기본 시동음은 OS가 올라오기 전 하드웨어 펌웨어(iBoot)에서 재생되는 소리라, macOS 보안 구조(SIP/SSV)상 서드파티 앱으로 그 타이밍 자체를 대체할 수는 없습니다.

로그 확인 및 완전 삭제

삭제할 때는 앱 하단의 등록 해제 버튼을 먼저 눌러 데몬과 공용 파일을 모두 지운 뒤, 응용 프로그램 폴더에서 MacBootSound.app을 삭제하면 깨끗하게 정리됩니다. 

# 부팅 사운드 로그 확인
cat /Library/Logs/MacBootSound.log

# 다른 맥에서 실행 시 격리 속성 해제가 필요한 경우
xattr -cr /Applications/MacBootSound.app
